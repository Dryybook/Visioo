# Maquettes VISIOO v1

`visioo-screens-v1.png` est la planche de référence UI fournie par le porteur du projet : 21 écrans mobile et Android TV.

Les affiches et visuels de films de la planche sont des **placeholders de maquette**. Ils ne doivent pas être livrés dans l'app : le catalogue vient du backend, avec des visuels sous licence.

## Écarts avec la spec à trancher
- Onglet « Téléchargements » (mobile) : la spec v1 est online-first, les téléchargements sont une fonction future.
- Onglets mobile des maquettes : Accueil, Explorer, Ma liste, Téléchargements, Profil. La spec prévoyait Accueil, Explorer, Recherche, Ma liste, Profil. La recherche passe en icône dans l'en-tête.
- Profil « Enfants » : le backend doit appliquer les restrictions de maturité.
